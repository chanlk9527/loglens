# LogLens

同一套日志解析与分析界面，提供独立浏览器版和 Electron 桌面版。桌面版增加本地日志诊断 Agent，支持 Windows / macOS 构建。AI 不要求输出确定根因：可以定位到有证据支持的环节，也可以明确回答证据不足。

## 直接使用

- 浏览器版：双击 `web/LogLens.html`。无需安装，不调用模型，保留导入、统计、筛选、请求看板、业务过程、原文定位和报告导出。
- 桌面安装包：本机打包已停用。Windows / macOS CI 配置已提供，尚未执行，当前没有经过最终验证的可交付安装包。
- 桌面开发运行：安装 Node.js 22+ 后执行以下命令。

Windows PowerShell（兼容公司透明加密源码）：

```powershell
npm ci --cache .npm-cache
.\desktop\run.ps1
```

macOS / 未受透明加密影响的开发环境：

```sh
npm ci
npm start
```

## 桌面使用流程

1. 拖入 `.log` / `.txt` / 普通 ZIP，或使用现有文件夹选择入口。也可以点击“试用示例”。格式和导入上限见 [浏览器说明](web/README.md)。
2. 日志只通过现有拖放 / 文件选择入口读取；无法取得明文时停止并查看导入明细，不从 JavaScript 启动 PowerShell 或自动切换读取进程。请使用公司允许导出的明文日志，不能通过本应用绕过安全工具。
3. 点击横向标签“AI 日志诊断”，展开“模型连接”，填写 API 根地址、模型名称和 API Key，点击“应用配置”。根地址示例 `https://your-provider.example/v1`，程序自动追加 `/chat/completions`。
4. 描述问题，可包含大概时间、设备和预期行为，点击“开始诊断”。当前问题和工具检索到的脱敏片段会发送至配置的模型。请使用允许发送的数据，自动脱敏不能保证发现所有敏感自由文本。
5. 查看实际查询进度、观察、候选解释、反证和补证建议。点击 `E...` 证据编号打开现有原文详情。可随时停止；重新导入会取消并使旧结果失效。

配置仅在主进程内存中保存，关闭应用清除，不把 Key 写入文件或打包进安装程序。也支持在启动进程设置 `AI_BASE_URL` / `AI_MODEL` / `AI_API_KEY`。当前调用协议要求模型支持 JSON 输出、`max_completion_tokens`、`store:false`；不同兼容服务需要实际联调。没有配置模型仍可使用全部原有分析功能。

## 架构与边界

```text
web/                 共享界面、解析器、业务规则、原文定位
  desktop-ui.js      仅检测到桌面桥时增加 AI 界面，浏览器中不执行
desktop/
  main.cjs           Electron 生命周期、受限 IPC、数据集与模型配置
  preload.cjs        隔离桥，只暴露固定方法，不暴露 Node / Shell
  store.cjs          本地数据集、稳定脱敏别名、搜索与证据读取
  agent.cjs          模型动作 → 本地工具 → 补充上下文 → 诊断校验
server/index.cjs     共用诊断约束、配置与结果校验；原 HTTP 接口仍可独立使用
```

日志解析仍复用前端 Worker。发起诊断时，将本次导入的解析事件通过本机 IPC 交给主进程；随后 Agent 自主检索，不需要前端每轮筛选，也不上传完整数据集。当前数据集最多 250,000 条事件、150 MiB IPC 内容；前端原有 100 MB 导入约束继续生效。

可用工具：概况、字面搜索（时间 / 业务过滤与分页）、同文件上下文、请求 / 操作 / 同设备关联、长消息片段读取。工具不提供任意命令执行或任意磁盘读取。关联工具明确区分直接标识、解析器回退配对和同设备可能相关。

工具每页默认8条，模型可选择1至20条；工作证据最多48条，调查笔记可固定8条关键证据。上下文按字节预算逐步移除未固定的旧证据、旧对话和查询历史，并标记被省略的对话数；固定证据与当前问题保留。状态硬上限72 KiB（另有固定系统提示），非精确token计数。每次输出最多4000 tokens。桌面 Agent 不设置单次请求或整体调查的应用层时间上限，等待模型返回；用户可手动停止，关闭窗口或切换数据集也会取消。快速排查最多12轮，深入调查最多32轮；轮数到达会暂停，用户可继续。网络、供应商或网关仍可能有自身超时策略。独立 HTTP 后端的旧单轮接口配置不影响桌面 Agent。

当前支持同一数据集上的持续对话、主动追问、带引用的调查笔记、反证核对、固定证据、预算暂停与继续。模型自主选择下一步工具，工具错误会反馈给模型修正；重复查询只提示，不强制终止。点击“新建调查”清空调查状态；关闭应用或导入新数据后会话失效。尚无跨启动持久化、向量索引、长期记忆、自动升级和团队认证。`.xlog` / `.mmap3` 仍需对应解码工具。

## 构建与验证

Windows：

```powershell
.\desktop\run.ps1 -Action Test
.\desktop\run.ps1 -Action Smoke
.\web\build.ps1
.\web\verify.ps1
.\server\start.ps1 -Test
```

PowerShell 启动器通过标准读取方式创建 `.desktop-stage/` 运行快照，随后 Electron 只读取快照。源码变更后重跑启动器即可。开发依赖在仓库根目录安装；Electron 下载缓存放在 `.electron-cache/`。

macOS：

```sh
npm run test:desktop
安装包通过 GitHub Actions 手动触发 Desktop build 工作流生成
```

Windows 已进行真实 Electron 窗口的合成数据验收，覆盖导入、三轮模拟模型调查、结果与证据跳转。测试不调用真实模型，不使用客户日志。macOS 提供构建配置与 CI，尚未在此 Windows 环境实机构建或验收；对外分发前需要 macOS 签名、公证和对应系统测试。Windows 预览版也尚未签名。

构建产物只包含应用源码、共享页面和 Electron 运行时；打包白名单排除了客户日志、环境文件、测试 fixture 和开发依赖。依赖版本由 package-lock.json 锁定，构建工具的审计结果需在正式发布前复核。

## 本机安全约束

应用不启动 PowerShell、cmd 或其他命令解释器。所有打包命令仅允许在 GitHub Actions 托管 runner 中执行，本机直接返回提示；不提权重试、不修改安全工具策略。CI 工作流尚未上传或触发。旧 dist 目录中的中间产物不是本次最终交付，不应分发。

构建依赖审计仍有未解决项（最近一次 npm audit：12 项，含 9 项 high；属于开发构建依赖）。当前为开发预览源码，不作为完成安全审查的正式发行版。

## 持续诊断验证

新增合成测试覆盖组合搜索、聚合、对比、追问后续查、笔记和关键证据保留、错误引用反馈修正、重复查询、预算暂停后继续、取消及跨数据集隔离。真实模型效果仍需接入用户配置的服务后评估；测试不把模拟模型成功等同于实际根因定位能力。
